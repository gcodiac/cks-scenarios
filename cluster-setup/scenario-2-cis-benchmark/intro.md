# CIS Kubernetes Benchmark

This scenario is the CIS Benchmark learning path for Kubernetes. Work through the four stages in order:

1. Learn to run and interpret `kube-bench`.
2. Remediate required workload and policy controls.
3. Investigate and harden a kubeadm control plane and worker configuration.
4. Build a repeatable production assessment process with evidence and exceptions.

The detailed material for each stage is kept in the `cis-benchmark-learn`, `cis-benchmark-required`, `cis-benchmark-inferno`, and `cis-benchmark-production` directories.
